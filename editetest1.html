Learn how Cascading Style Sheets bring HTML to life.

1. What is CSS?

While HTML provides the structure of a webpage (like the skeleton), CSS (Cascading Style Sheets) handles the presentation, styling, layout, and colors (like the skin, clothes, and design).

2. Essential CSS Properties

Here are some of the most common properties you will use every day:

  • color: Changes the text color.
  • background-color: Sets the background color behind an element.
  • font-size: Controls how large or small text appears.
  • padding: Adds space inside an element around its content.
  • margin: Adds space outside an element to separate it from others.

Did you know?

CSS allows your website to adapt to different screen sizes, ensuring your pages look great on both desktop computers and mobile phones!
